# Anti-AI-Comments
this is a simple C code that can scan C files only (for now) and delete all the comments in it. The core use of this is if your (vibecoded)
app has too many comments and you want to delete them.
BEWARE!!! THIS PROGRAM ONLY WORKS ON C FILES FOR NOW AND IF YOU HAVE // IN THE MIDDLE OF YOUR PROGRAM IT WILL GET DELETED !!!BEWARE
